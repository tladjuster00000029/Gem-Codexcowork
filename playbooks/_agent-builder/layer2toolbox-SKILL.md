# 목적
방금 만들어 통과한 산출물(스크립트, 템플릿, 이메일, 체크리스트, 규칙, 예시)을 재사용 가능한 툴박스 파일로 만들고 `SKILL.md`에 연결한다.

# 언제 쓰는지
내가 특정 산출물을 가리키며 "레이어 2: 툴박스에 저장해"라고 말할 때 실행한다.

# 실행 순서
1. 방금 통과한 산출물이 저장 가능한 대상인지 먼저 확인해라.
   - 저장 대상: 기계적 단계 스크립트, 대괄호 자리표시자(`[ ]`) 템플릿, 참조 데이터(고객명·제품·링크), 만족한 완성 예시, 규칙 파일(톤·금지어), 하위 단계용 프롬프트
   - 저장 금지: 일회성 산출물, 비밀번호나 API 키가 포함된 것, 내가 승인하지 않은 반쪽짜리 초안
2. 재사용 가능하도록 내 상황에 특화된 부분을 `[대괄호 자리표시자]`로 바꾸고, 바로 아래에 실제 값이 채워진 예시 하나를 참조로 남겨라.
3. 저장할 파일 이름을 날짜나 버전 번호 없이 설명적인 이름으로 지정해라 (예: `[job-name]/files/numbers-pull.py`, `[job-name]/files/update-template.md`). 완성 작례는 `[job-name]/examples/YYYY-MM-DD-good.md`로 지정해라.
4. `[job-name]/SKILL.md`를 업데이트하여 해당 단계가 이 파일 이름을 정확히 가리키게 하고, 언제 쓰고 언제 안 쓰는지도 명시해라.
5. `[job-name]/files/INDEX.md`에 추가할 한 줄(파일명 | 용도 | 오늘 날짜)을 작성해라.
6. 전체 업무를 처음부터 다시 시뮬레이션하여 어떤 저장 파일을 썼고 무엇을 백지에서 새로 지었는지 알려라. 백지에서 다시 지은 것 중 다음에 툴박스로 저장할 후보를 제안해라.

# 파일 저장 및 교체 규칙 (필수 동의 절차)
- 파일을 직접 쓸 수 없다면 쓴 척하지 마라.
- 새로 만든 툴박스 파일, 업데이트된 `SKILL.md`, 업데이트된 `INDEX.md`의 전체 내용과 정확한 폴더 경로를 각각 출력해라.
- 출력 후 **"이 변경사항에 동의하시면 내 컴퓨터 폴더에 저장하고, 프로젝트에 업로드된 예전 `SKILL.md`와 `INDEX.md` 복사본을 삭제한 뒤 새 파일로 교체해 주세요."**라고 동의를 구해라.
