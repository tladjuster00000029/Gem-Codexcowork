# 목적
반복 업무를 인터뷰하여 나 없이도 AI가 단독 실행할 수 있는 `[job-name]/SKILL.md` 초기 매뉴얼을 생성한다.

# 언제 쓰는지
내가 "레이어 1 시작: [업무 한 줄 설명]"이라고 말할 때 실행한다.

# 실행 순서
1. 먼저 나를 인터뷰해라. 한 번에 질문 하나만 하고 내 답을 기다려라.
2. 최소 8개의 질문을 하고, 내가 "끝났다"고 말하기 전까지 절대 파일을 먼저 쓰지 마라.
3. 인터뷰에서 다음 8가지를 반드시 전부 다뤄라:
   - 이 일을 시작하게 만드는 계기와 빈도
   - 입력 데이터들과 각각의 정확한 위치
   - 실제로 내가 하는 순서대로의 단계들
   - 내가 내리는 모든 결정과 그 뒤의 판단 규칙
   - 끝냈다고 부르기 전에 내가 확인하는 것들
   - 예전에 잘못됐던 예외 사례들
   - 결과물이 만족해야 하는 톤이나 기준
   - 나쁜 버전(실패작)이 어떻게 생겼는지
4. 나 없이도 이 일을 돌릴 수 있겠다 싶으면 `[job-name]/SKILL.md` 초안을 작성해라. 포함할 섹션은 다음과 같다:
   - 목적 (한 줄)
   - 언제 쓰는지 (내가 이 일을 시킬 때 실제로 칠 말 그대로)
   - 입력
   - 순서 (번호 매기기, 쉬운 말, 전문용어 배제)
   - 결정 ("X면 Y다" 형식)
   - 완료의 정의
   - 예외 사례
5. 파일 전체 내용을 코드 블록으로 출력한 뒤 다음 두 가지를 질문해라:
   - 내가 잘못 뽑아낸 것이 무엇인지
   - 내가 아직 알려주지 않은 것이 무엇인지

# 파일 저장 및 교체 규칙 (필수 동의 절차)
- 파일을 직접 쓸 수 없다면 쓴 척하지 마라.
- 전체 파일 내용을 채팅에 출력하고, 내 컴퓨터에 저장할 정확한 파일명과 폴더 경로(`[job-name]/SKILL.md`)를 명시해라.
- 마지막에 반드시 **"이 내용으로 확정하여 로컬 폴더에 저장하고 프로젝트 파일을 교체하시겠습니까?"**라고 내 동의를 구해라.
- 내가 동의하면, 내 컴퓨터 폴더에 파일을 저장한 뒤 프로젝트에 업로드된 기존 복사본을 지우고 새 파일로 교체하라고 안내해라.
